# مدونة أحمد عباس الملجمي — almaljamie.my

المدونة مبنية بـ [Eleventy](https://www.11ty.dev)، ومستضافة مجانًا على GitHub Pages. عند كل تعديل يُرفع إلى المستودع، يُبنى الموقع ويُنشر تلقائيًا خلال دقيقة أو دقيقتين.

## إضافة مقال جديد

1. افتح مجلد `src/posts/` في المستودع على GitHub، ثم اختر **Add file ← Create new file**.
2. سمِّ الملف بالتاريخ واسم قصير بحروف لاتينية، مثل: `2026-12-01-qabali.md`.
   الجزء اللاتيني من الاسم يظهر في رابط المقال: `almaljamie.my/articles/qabali/`
3. انسخ هذا القالب في أول الملف، ثم اكتب المقال تحته:

```
---
title: عنوان المقال
date: 2026-12-01
category: البيضاء
summary: سطر أو سطران يلخصان المقال، ويظهران في الصفحة الرئيسية وعند مشاركة الرابط.
---

الفقرة الأولى من المقال.

الفقرة الثانية. اترك سطرًا فارغًا بين كل فقرتين.

## عنوان فرعي

> اقتباس يظهر بخط مميز.
```

4. اضغط **Commit changes**، وسيظهر المقال في الموقع خلال دقيقتين تقريبًا.

**حقول اختيارية:** إذا نُشر المقال في منصة أخرى، فأضف السطرين التاليين بين علامتي `---`:

```
source: منصة شمّر
sourceUrl: https://...
```

## تعديل بياناتك

- **البريد وحسابات التواصل:** في الملف `src/_data/site.json`. الحقول الفارغة لا تظهر في الموقع.
- **صورتك الشخصية:** ارفعها إلى `src/images/` باسم `author.jpg`. يُفضّل أن تكون مربعة بعرض 400 بكسل تقريبًا.
- **الدراسات:** في الملف `src/research.njk`.
- **صفحة «عن الكاتب»:** في الملف `src/about.njk`.

## التشغيل على جهازك (اختياري)

```
npm install
npm start
```

ثم افتح الرابط `http://localhost:8080`.
