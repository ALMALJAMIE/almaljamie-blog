# مدونة أحمد عباس الملجمي — almaljamie.my

المدونة مبنية بـ [Astro](https://astro.build)، وتصميمها بـ Tailwind، والبحث داخل المقالات بـ Pagefind. وهي مستضافة على GitHub Pages، فعند كل تعديل يُرفع إلى المستودع يُبنى الموقع ويُنشر تلقائيًا خلال دقيقتين.

## إضافة مقال جديد

1. افتح مجلد `src/content/posts/` على GitHub، ثم اختر **Add file ← Create new file**.
2. سمِّ الملف بالتاريخ واسم قصير بحروف لاتينية، مثل: `2026-12-01-qabali.md`.
   الجزء اللاتيني من الاسم يظهر في رابط المقال: `almaljamie.my/articles/qabali/`
3. انسخ هذا القالب في أول الملف، ثم اكتب المقال تحته:

```
---
title: عنوان المقال
date: 2026-12-01
category: البيضاء
summary: سطر أو سطران يلخصان المقال، ويظهران في الصفحة الرئيسية وعند مشاركة الرابط.
---

الفقرة الأولى من المقال.

الفقرة الثانية. اترك سطرًا فارغًا بين كل فقرتين.

## عنوان فرعي

> اقتباس يظهر بخط مميز.
```

4. اضغط **Commit changes**، وسيظهر المقال في الموقع خلال دقيقتين تقريبًا.

**الحقول الاختيارية**، وتُكتب بين علامتي `---`:

| الحقل | معناه |
|---|---|
| `source: منصة شمّر` | منصة أخرى نُشر فيها المقال |
| `sourceUrl: https://...` | رابط المقال في تلك المنصة |
| `cover: /images/صورة.jpg` | صورة غلاف. إن لم تضعها، يُولَّد للمقال غلاف تلقائي على شكل واجهة بيت يمني |
| `draft: true` | مسودة لا تظهر في الموقع |

## إضافة دراسة للتنزيل

1. ارفع ملف الدراسة بصيغة PDF إلى مجلد `public/files/`، وسمِّه بحروف لاتينية، مثل: `social-determinants.pdf`.
2. افتح مجلد `src/content/studies/`، وأنشئ ملفًا جديدًا مثل `social-determinants.md`، أو عدّل ملفًا موجودًا:

```
---
title: عنوان الدراسة
type: دراسة محكّمة
status: published
journal: اسم المجلة
issue: المجلد 5، العدد 2
year: 2025
pdf: /files/social-determinants.pdf
summary: سطران يلخصان الدراسة.
order: 30
---
```

- `status: in-progress` يعني أن الدراسة قيد الإنجاز، فلا يظهر لها زر تنزيل.
- `order` يحدد الترتيب: الرقم الأكبر يظهر أولًا.
- `cover: /images/غلاف.jpg` اختياري. إن لم تضعه، يُصمَّم للدراسة غلاف تلقائي.

## تعديل بياناتك

- **البريد وحسابات التواصل:** في الملف `src/data/site.ts`. الحقول الفارغة لا تظهر في الموقع.
- **صورتك الشخصية:** ارفعها إلى `public/images/` باسم `author.jpg`، ويُفضّل أن تكون مربعة.
- **السيرة الذاتية:** `src/pages/cv.astro`، والبيانات والأقسام في أول الملف.
- **مفكرة الباحث الذكية:** `src/pages/notebook.astro`

## التشغيل على جهازك (اختياري)

```
npm install
npm run dev
```
